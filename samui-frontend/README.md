# Samui 3D Geo-Risk Watch (Frontend v2.6)

ระบบเฝ้าระวังภัยธรรมชาติภูมิสารสนเทศ 3 มิติ เกาะสมุย จ.สุราษฎร์ธานี

## วิธีติดตั้งและรันโปรเจกต์
1. เปิด Terminal ในโฟลเดอร์ samui-frontend
2. ติดตั้งไลบรารี:
   npm install
3. รันเซิร์ฟเวอร์พัฒนา (พอร์ต 3001):
   npm run dev
4. เปิดเบราว์เซอร์ไปที่ http://localhost:3001
